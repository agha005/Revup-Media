# RevUp Media Portfolio — Local Project

This folder contains the complete local website. It is not connected to a hosting service.

## Open the website

Double-click `OPEN-WEBSITE.bat`, or open `index.html` in a browser.

## Open the project in VS Code

1. Open Visual Studio Code.
2. Select **File → Open Folder**.
3. Choose this folder:

   `C:\Users\WAL\Desktop\raveup website\raveup website`

The main homepage file is `index.html`. Shared styling is in `assets/styles.css`, and shared interactions are in `assets/site.js`.

For live reload while editing, use the VS Code Live Server extension and select **Open with Live Server** on `index.html`.
